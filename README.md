This MODAQ2 Reference Design is an example build of a MODAQ2 system. It pulls in multiple submodules of ros2/m2 packages.

This is a good starting point to learn MODAQ2 but for custom builds, we recommend building your own ros2 workspace with our modules. To learn how to do this, please visit:
https://natlabrockies.github.io/MODAQ2/github/




To Setup:
```bash
git clone https://github.com/MODAQ2/MODAQ2-RD.git --recurse-submodules
git submodule init
git submodule update
```
